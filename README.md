# Event Attendance Tracking System

## Project purpose
A student and admin system for creating events, registering students, recording attendance, and viewing reports.

## Technology plan
- Database: MySQL
- Server/API: Node.js with Express
- Database connection for the DBMS demonstration: PHP
- Frontend: HTML, CSS, and JavaScript
